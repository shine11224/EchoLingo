# 百度网盘持久化队列与“我的网盘”实施计划

## 已确认边界

- 单文件上限 1GB；分享链接和“我的网盘”共用导入任务体系。
- 多用户普通用户只可提交分享链接；管理员另可浏览已授权账号的完整目录并单选文件。公开版由部署者在命令行授权，不提供网页授权。
- 两个并发下载槽、全局 FIFO、每用户最多一个非终态任务；普通用户每日 3GB，管理员免配额但不插队。
- 任务写入独立 SQLite；服务重启后排队任务恢复，下载中任务标为可重试的中断状态。
- 提取码仅驻留进程内存；重启后任务等待用户补充。Token、完整管理员网盘路径、完整分享链接不进入对外审计。
- 支持取消与人工重试；失败/取消立即清理临时文件和转存副本，成功资产跟随课程生命周期。
- 下载前校验文件 ID、大小、修改时间和磁盘余量（文件大小 + 2GB）；授权失效暂停队列，恢复后自动继续。
- 文件浏览器提供面包屑、分页（50/页）、排序和全局搜索（最多 200 条）；不支持或超过 1GB 的文件显示但不可选，不生成预览。
- 普通用户仅看自己的任务；管理员可看全部脱敏审计；终态任务保留 7 天。

## 实施顺序

1. 建立独立任务库、状态机、配额预占与重启恢复。
2. 将转存锁缩短到转存阶段，下载改为默认并发 2 的信号量调度。
3. 增加目录/搜索/直接导入、取消、重试、补充提取码 API，并补齐权限守卫。
4. 私有账号设置页增加授权引导；公开版首页仅显示命令行授权说明与重新检测。
5. 首页百度网盘区改为双入口，管理员/单用户增加完整文件浏览器和任务进度。
6. 回归测试、索引/部署文档更新；按公开同步清单排除账号与凭据模块后同步公开库，并部署私有云端。
